# TravelMate - Travel & Hospitality Webpage

Website Link : https://travel-hospitality-ui.vercel.app/


A modern, responsive frontend webpage for a travel planning service called TravelMate.

## Features    

- **Hero Section**: Eye-catching video background with search functionality
- **Navigation**: Fixed navigation bar with smooth scrolling
- **Destinations**: Showcase of popular travel destinations with hover effects
- **About Section**: Features highlighting the service benefits
- **Trip Planning**: Interactive itinerary generator based on user preferences
- **Responsive Design**: Works on desktop and mobile devices
- **Modern UI**: Clean design with animations and transitions

## How to Use

1. Open `index.html` in your web browser
2. Enter a destination in the search field
3. Select your travel interest from the dropdown
4. Click "Plan My Trip" to generate a personalized itinerary
5. Scroll through the page to explore destinations and features
